# XATU Helper

西安工业大学的校园信息整合 App。登录学校统一身份认证后，把课程表等常用的内容收进一个 App 里，随手打开就能看。

> Android 版本仍在迁移的早期阶段，不可用，请勿安装到日常使用的主力机。目前只有 iOS 版能正常用，详见下方「Android」一节。

## 能做什么

- **课程表**：按周查看，可以切换学期，也能在学生课表和班级课表之间切换。
- **考试安排**：随时查看考试安排。
- **成绩**：随时查看当前学期与所有学期成绩。
- **电费**：一键查询宿舍余额、充值入口、近 7 天用量统计曲线和历史余额。
- **提醒**：上课前和考试前的本地通知，时间可自己调。

## 使用

1. 安装到 iPhone（iOS 17+）。
2. 打开它，没了。

账号和密码和所有 App 读到的信息都只保存在本机钥匙串里，不经过任何第三方服务器。App 不会上传任何东西到任何地方。

## Android（Skip Fuse，早期迁移版）

**Android 版本仍是迁移的早期版本，不可用，不要拿去当日常 App 用。**

现在的状况：

- 只验证了能编译、能装、能启动：Android Swift 交叉编译、Gradle `assembleDebug`、APK 签名校验、iOS Simulator 编译和 3 项核心回归测试通过，Android 16 ARM64 模拟器上能安装并冷启动。
- 没有用真实的学校账号跑通过：统一身份认证（含验证码和网页登录）、课程表、成绩、考试、培养计划、电费接口、网页签到定位、通知到达与重启恢复、桌面小组件，都还没在校园网下实测。
- 调试包约 280 MB，用调试签名，不能发布；省电策略和厂商后台限制对提醒的影响也没验证。
- 接口和行为都没稳定，随时会有破坏性改动。

迁移工程在 [xatu-android](xatu-android/README.md)。想帮忙调试的话，用 Android Studio 打开 `xatu-android/Android`，或运行 `./xatu-android/scripts/build-android.sh` 构建调试 APK。原 iOS 工程保持独立。
